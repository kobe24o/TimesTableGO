# TimesTableGO Flutter 跨平台迁移设计

## 目标与范围

使用同一套 Flutter 代码交付 Android 和 iOS 乘法练习应用，保留中英文、离线语音练习、学习统计与设置，适当美化 UI，并将 iOS 构建上传 TestFlight。Apple 开发权限参考相邻 bible_recite 项目。无需账户登录或云端语音服务。

## 技术选择

选择 Flutter：参考项目已使用 Flutter，本机已有对应 SDK，可共享界面与练习逻辑。继续分别维护 Kotlin 和 Swift 会重复实现产品功能；把现有页面包装为网页不能直接复用离线模型，且会增加音频处理复杂度。

新应用先放在仓库 `flutter_app/`，原 Android 工程作为行为和资源参考，迁移验证通过后将 CI 的正式构建入口切换到 Flutter。Android 沿用 `com.example.multiplicationcoach` 与现有签名，版本号高于当前 0.1.11 / 12。iOS 拟用 `app.timestablego`，注册前检查唯一性，使用团队 `P24F5QH7BB`；不复用 Bible Recite 的应用标识或描述文件。

Flutter 负责页面、业务状态、统计、答案解析及本地存储。使用 sherpa-onnx 的 Flutter/Dart 接口调用 SenseVoice 与 Silero VAD；采用跨平台录音与音频播放插件。具体包版本在依赖解析时核实并锁定，确认支持本机 Flutter 及目标平台。识别在后台 isolate 执行，避免阻塞动画和操作。

## 功能与交互

练习页展示当前题目、准备/播放/录音/识别/反馈状态和倒计时，主按钮开始或停止。题库包含 1–9 两个因子的全部 81 个有序组合，随机出题。默认开启读题、英语、3 秒答题时间（依用户后续要求更新；升级保留已有语言）；设置可切换语言、开关读题、调整 1–15 秒时限。

题目音频播完后才打开麦克风，倒计时从录音实际开始计算。采样为 16 kHz 单声道 PCM；用 VAD 识别语音段，同时保留整段短回答识别作为回退。全程本机处理，不上传录音，不把识别结果替换成预期答案。没有数字或没有语音时重复当前题、不计错；正确或错误均先完整播放反馈，错误时展示正确答案并播放逐题订正，再进入下一题。数字解析支持阿拉伯数字、中文数字、英文数字和与当前题目匹配的完整算式；冲突答案不能因为包含预期数字就自动判对。

统计页保留总练习、正确率、当前连对、81 题覆盖率、正确率走势、九九表掌握度矩阵、六个成就与最近十次作答。成就阈值沿用 Android：完成首题；至少十题且正确率 80%；连对十题；至少五十题且正确率 95%；覆盖全部 81 题；累计一百题。提供清空记录操作并二次确认。

设置与作答记录持久化在本地，重启恢复。Android 升级时通过平台通道导入原 `practice` SharedPreferences 中的设置和历史，迁移成功标记后不重复导入；新 iOS 安装从空记录开始。损坏记录提示恢复措施，避免静默伪造或覆盖原记录。

## 视觉设计

采用温暖浅色背景、深蓝文字和青绿色主色，练习/统计/设置三个底部导航。练习题目居中放大，录音时用柔和呼吸动画与进度环展示剩余时间；正确和错误反馈同时使用文字、图标与颜色。统计使用圆角卡片和可读的掌握度矩阵。适配 iPhone、iPad 和 Android 常见屏幕，支持安全区域、大字体、屏幕阅读器及减少动态效果设置，主要按钮触控区域至少 48 逻辑像素。

## 资源与离线能力

复用原 81 题读题、81 题订正和通用反馈的双语资源及许可证。现有 Ogg 音频在 iOS 上进行真实播放验证；若播放器不能支持，则开发期统一转为两端支持的 AAC 或 WAV，保留中文与英文完整映射。音频缺失时明确显示文字回退，不能播放错误语言冒充成功。

模型文件当前为 Git LFS 指针，必须取回真实资源。安装到可读本地目录后对照原 manifest 校验 SHA-256，校验通过才创建识别器。模型、令牌、VAD 和许可证随包交付，首次启动不要求下载；模型不可用时显示可理解的错误并禁用开始语音练习，不能以在线识别代替。

## 生命周期与错误处理

拒绝麦克风权限时说明用途并提供进入系统设置的入口。停止、切换语言、切换页面和进入后台都取消当前练习并释放录音；停止后异步识别结果不得更新成绩。电话或音频中断时暂停练习，用户主动恢复。播放失败提供文字回退；录音或识别失败显示重试，不记为答错。

## 发布与凭据

复用 bible_recite 的手动签名和 GitHub Actions 发布方式，使用 TimesTableGO 自己的工作流、描述文件、App Store Connect 记录和测试组。Apple API 私钥、证书已上传 TimesTableGO 仓库；证书导出密码尚缺，证书归属与有效期尚待解锁后验证。API Key ID / Issuer ID 已配置为仓库变量。不得将私钥或密码写入 Git 或日志。

先完成分析、测试、Android 构建和 iOS 模拟器构建，再执行 Release 归档与签名上传。上传后确认 Apple 处理成功，再分配外部测试组并提交 Beta 审核；只有 Apple 批准并实际可安装时才宣称可供外部测试。TestFlight 发布属于此次授权范围，公开 App Store 正式发布不包含在内。

Android 原有签名更新协议需保留：签名清单、网络下载策略、大小/摘要/包名/版本/证书校验和系统安装确认，Flutter 页面通过平台适配调用；iOS 更新通过 TestFlight/App Store。

## 验收证据

1. 单元测试：81 题、双语数字/算式解析、冲突和越界、无语音重复、倒计时、统计及成就阈值、持久化与 Android 迁移。
2. 流程测试：音频播完再录音、实际录音起点计时、停止和后台取消、语言切换、录音拒绝与错误恢复；防止过期异步结果计分。
3. 资源检查：真实模型大小及摘要、双语完整音频清单、许可证齐全。
4. 运行 Flutter 静态分析和全部测试，构建 Android APK 和 iOS 模拟器应用；在模拟器检查三个页面、中英文、大小屏及大字体。
5. 在真实 iOS / Android 设备飞行模式下验证中英文语音识别、音频反馈、权限与后台中断；模拟器构建不能替代真机音频验收。
6. Android 发布包可验证升级签名与历史迁移；iOS 归档验证并上传，记录构建号和 Apple 处理/审核状态。
